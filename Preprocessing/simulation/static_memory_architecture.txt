--------------------------------------------------------------------------------
1. MOTIVATION & MISRA-C COMPLIANCE
--------------------------------------------------------------------------------
In an embedded GPS navigation system:
1. Heap Fragmentation: Repeated routing of variable lengths fragments the heap
   over runtime, eventually causing malloc() to fail unpredictably.
2. Non-Deterministic Latency: Dynamic heap allocators do not guarantee O(1)
   execution time, violating hard real-time deadlines.
3. MISRA-C Rule 21.3: Dynamic heap allocation (malloc, calloc, realloc, free)
   is strictly prohibited in safety-critical firmware.
4. Determinism: Every byte of working memory is given a fixed address in the
   .bss segment or memory-mapped ROM/flash at compile-time.

--------------------------------------------------------------------------------
2. COMPONENT SPECIFICATIONS & STATIC POOLS
--------------------------------------------------------------------------------

A. A* Min-Heap Priority Queue (astar_heap.h / astar_heap.c)
   - Before: Dynamically allocated heap->entries via malloc(), resized via realloc().
   - After:  Fixed array embedded directly into AstarHeap struct:
             #define ASTAR_HEAP_MAX_ENTRIES 32768
             typedef struct {
                 HeapEntry entries[ASTAR_HEAP_MAX_ENTRIES];
                 int32_t size;
             } AstarHeap;
   - Footprint: 32,768 entries * 12 bytes = 384 KB in .bss.
   - Operations: astar_heap_init() resets size = 0. Zero heap overhead.

B. Spatial Tile Graph Cache (tile_graph_cache.h / tile_graph_cache.c)
   - Before: malloc(n_size) for NodeRecord array and malloc(e_size) for EdgeRecord.
   - After:  Dedicated static 2D pools in .bss sized to maximum observed records:
             #define TILE_GRAPH_CACHE_MAX_LOCAL 4
             #define TILE_MAX_LOCAL_NODES      24000
             #define TILE_MAX_LOCAL_EDGES      45000
             #define TILE_MAX_BACKBONE_NODES   90000
             #define TILE_MAX_BACKBONE_EDGES  130000

             static NodeRecord s_local_node_pool[4][24000];
             static EdgeRecord s_local_edge_pool[4][45000];
             static NodeRecord s_backbone_node_pool[90000];
             static EdgeRecord s_backbone_edge_pool[130000];

   - Pinning: Active A* search session tiles are pinned (pin_count > 0) to
     prevent eviction during cross-tile border exploration.
   - Eviction: Overwrites unpinned slots using fread(). free_graph() closes
     file handles and resets loaded flags without freeing any buffer.

C. A* Pathfinding Working State (pathfinder.h / pathfinder.c)
   - Before: Dynamic per-query malloc() for g_scores, came_from_keys,
             came_from_edges, temp_segs, segments, geom_points.
   - After:  Statically allocated working arrays in .bss:
             static uint32_t s_local_g_scores[4][24000];
             static uint32_t s_local_came_from_keys[4][24000];
             static uint32_t s_local_came_from_edges[4][24000];

             static uint32_t s_bb_g_scores[90000];
             static uint32_t s_bb_came_from_nodes[90000];
             static uint32_t s_bb_came_from_edges[90000];

             static RouteSegment s_temp_segs[2048];
             static AstarHeap    s_astar_heap;

D. Route Result Output (RouteResult)
   - Before: Dynamically realloc'd segments and geom_points pointers.
   - After:  Bounded static arrays embedded in RouteResult:
             #define ROUTE_MAX_SEGMENTS    2048
             #define ROUTE_MAX_GEOM_POINTS 16384
             typedef struct {
                 RouteSegment segments[ROUTE_MAX_SEGMENTS];
                 int32_t segment_count;
                 uint32_t total_distance_m;
                 uint32_t total_time_sec;
                 GeomPoint geom_points[ROUTE_MAX_GEOM_POINTS];
                 int32_t geom_point_count;
                 bool found;
                 int routing_mode;
             } RouteResult;

   - RouteSegment Optimization: Replaced 512-byte char geom_path[512] with
     const char *geom_path referencing TileGraph persistent string.
     Reduces sizeof(RouteSegment) from 552 bytes to 40 bytes!

E. Map Tile Texture Cache (tile_cache.h / tile_cache.c)
   - Before: calloc() for TileCacheEntry array and free() on destroy.
   - After:  TileCacheEntry entries[TILE_CACHE_DEFAULT_CAPACITY] inline array.

--------------------------------------------------------------------------------

mapped directly in Flash ROM, reducing total RAM requirement to < 1.8 MB).
